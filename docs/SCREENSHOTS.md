# 📸 IMovies Screenshot Checklist & Evaluation Guide

This document provides a structured guide and evaluation checklist of all primary views within **IMovies — Movie Ticket Booking Made Simple**.

When preparing your final evaluation submission or Skill Wallet presentation, capture screenshots corresponding to each section below.

---

## Screenshot Checklist

| Item # | View / Feature | Description | Key Elements to Highlight |
|---|---|---|---|
| **01** | **Homepage & Hero Showcase** | Main entry view showcasing featured blockbuster and navigation | • Trending movie hero banner<br>• Search bar and genre filter chips<br>• Movie cards with rating badges |
| **02** | **Authentication & Demo Modal** | Modal dialog for registration and user login | • One-click "Demo User" and "Demo Admin" buttons<br>• Form validation and JWT handling |
| **03** | **Movie Details & Showtimes** | Detailed view for selected film | • Movie poster, synopsis, cast, and director<br>• Date selector tabs (Today / Tomorrow)<br>• Cinema hall cards with showtime chips |
| **04** | **Interactive Cinema Seat Map** | Graphical theater auditorium seat selector | • Curved projection screen indicator<br>• Standard, Premium, and VIP seat tiers<br>• Real-time seat states (Selected, Booked, Locked)<br>• Sticky bottom total pricing bar |
| **05** | **Simulated Payment Gateway** | Multi-method checkout modal | • Order breakdown with taxes & convenience fee<br>• Payment methods: Card, UPI, Net Banking, Wallet<br>• Instant simulated 256-bit encryption confirmation |
| **06** | **E-Ticket Voucher with QR Code** | Confirmation dialog with printable ticket | • Unique Booking Reference (e.g. `IM-K7X9Q4L2`)<br>• Scannable QR code visual<br>• Print ticket & view history buttons |
| **07** | **Customer Booking History** | List of user's past and upcoming tickets | • Confirmed vs. Cancelled status badges<br>• View Ticket and Cancel Ticket actions |
| **08** | **Admin Dashboard & Analytics** | Cinema management portal | • KPI cards: Total Revenue, Bookings, Active Movies, Users<br>• Database engine status indicator<br>• Add New Movie form<br>• System-wide box office transaction table |

---

## Visual Presentation Tips for Evaluation
1. **Resolution**: Take full-window browser screenshots at 1920x1080 (1080p).
2. **Browser Dark Theme**: Use dark mode to complement the cinema aesthetics.
3. **Demo User Walkthrough**: Highlight the instant 1-click login feature that lets evaluators test without manual account setup.
